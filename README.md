# 🎮 Retro Smart Cast Website

A premium, high-performance landing page for **Retro Smart Cast**—the ultimate GBA, GBC, and GB emulator for Android.

Built with a modern **glassmorphic** aesthetic, this website is designed to provide a sleek and professional introduction to the emulator's core features while maintaining high performance and responsiveness.

![Retro Smart Cast Hero Section](https://github.com/davidkalil10/Retro-Smart-Cast-Website/blob/main/hero%20cover%2010%203.png?raw=true)

## ✨ key Features

- **🎯 Gaming-First Design**: Custom-crafted color palette (Cyan/Magenta) and interactive elements for a premium handheld experience.
- **⚡ 60 FPS Performance**: High-speed emulation using optimized Dart FFI bridges between Flutter and C++.
- **🔎 Dynamic Search**: Real-time library filtering to find and organize your favorite titles instantly.
- **📳 Haptic Immersion**: High-quality tactile feedback for virtual buttons to enhance the handheld feel.
- **🌍 Full Localization**: Multi-language support for English, Portuguese, and Spanish (EN/PT/ES).
- **🚀 Ultra-Fast Performance**: Lightweight landing page structure built for instant loading.
- **✨ Animated Micro-interactions**: Smooth transitions and "floating" elements for a dynamic user experience.
- **🛡️ Integrated Legal notice**: Clear and professional communication regarding ROM ownership and privacy policy.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript.
- **Emulation Engine**: [SkyEmu](https://github.com/skylot/SkyEmu) (MIT License).
- **App Core**: Flutter (Dart) with Custom Dart FFI Bridge (Native C++).
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Custom Configuration).
- **Icons**: [FontAwesome 6](https://fontawesome.com/).
- **Typography**: [Google Fonts (Outfit)](https://fonts.google.com/specimen/Outfit).

## 🚀 Getting Started

To run this website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/davidkalil10/Retro-Smart-Cast-Website.git
   ```
2. Open `index.html` in your browser or use a live server extension (like Live Server for VS Code).

### Asset Management
The website uses the following placeholders for branding:
- `app_icon_1440.png`: App icon (recommended 1024x1024+).
- `hero cover 10 3.png`: Hero section background banner.

Simply replace these files in the root directory to update the branding.
